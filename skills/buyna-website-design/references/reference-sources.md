# External Design And Template Research

Browse current pages during each project; external content, pricing, and licenses can change.

## Inspiration Sources

- Awwwards: `https://www.awwwards.com/` — broad award-focused visual references.
- Land-book: `https://land-book.com/` — curated landing pages and page patterns.
- Godly: `https://godly.website/` — contemporary web and motion inspiration.
- Lapa Ninja: `https://www.lapa.ninja/` — landing-page sections and conversion patterns.

## Template Sources

- Figma Community: `https://www.figma.com/community` — design files and UI kits; verify each item's creator and license.
- Framer Marketplace: `https://www.framer.com/marketplace/templates/` — Framer templates; verify price and usage terms.
- Webflow Templates: `https://webflow.com/templates` — Webflow templates; verify platform fit and license.
- Next.js Templates: `https://nextjs.org/templates` — framework-aligned starter templates; inspect repository and license.

## Team-Provided Sources

- Swiper Studio: `https://studio.swiperjs.com/` — a visual builder and template source for responsive sliders and carousels. Use it when exploring hero banners, product showcases, testimonials, image galleries, and other swipe-based sections. It can export to HTML, React, Vue, Next.js, Web Components, Webflow, CDN, or iframe. Treat it as a component and interaction reference, not as the design direction for the entire website. Before reuse, verify current pricing, license, framework compatibility, accessibility, mobile behavior, performance, and reduced-motion behavior.

## Research Output

For each recommended link, record:

- URL and title.
- Why it matches this customer.
- What to study: typography, hero, navigation, section rhythm, motion, forms, or mobile behavior.
- Inspiration only or reusable template.
- Framework/platform.
- Free, paid, or unknown until verified.
- License/attribution status.
- Elements that must not be copied.

If no suitable template exists, say so and continue with a custom design direction. Do not block the project because an internal template library does not exist yet.
